# Expected SHA256 checksums for the published prebuilt converter assets.
#
# scripts/build-rust-converter.js verifies every downloaded asset against THIS
# committed file. It deliberately does not use the checksums.txt published
# alongside the release: verifying a download against a checksum fetched from
# the same URL proves only that the transfer was not corrupted, not that the
# bytes are the ones this repo intends to run. Whoever can publish the release
# can publish a matching checksum.
#
# The version below must match the "version" field in
# scripts/rust-markdown-converter/package.json. When the converter version is
# bumped and a new release is published, refresh this file with:
#
#   node scripts/update-converter-checksums.js
#
# Until it is refreshed, installs fall back to building from source rather than
# trusting an unverified download.
#
# version: v0.1.0
