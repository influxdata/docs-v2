
The `influxd` command starts and runs all the processes necessary for InfluxDB to function.

## Usage

```
influxd [[command] [arguments]]
```

## Commands
| Command                                               | Description                                              |
|-------------------------------------------------------|----------------------------------------------------------|
| [backup](/product/version/tools/influxd/backup)   | Download a snapshot of a data node and saves it to disk. |
| [config](/product/version/tools/influxd/config)   | Display the default configuration.                       |
| help                                                  | Display the help message.                                |
| [restore](/product/version/tools/influxd/restore) | Use a snapshot of a data node to rebuild a cluster.      |
| [run](/product/version/tools/influxd/run)         | Run node with existing configuration.                    |
| [version](/product/version/tools/influxd/version) | Display the InfluxDB version.                            |
